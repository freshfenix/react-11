# Dayflow — планувальник щоденних звичок

Dayflow — україномовний адаптивний React-застосунок для формування корисних звичок. Він допомагає спланувати невеликі щоденні кроки, відстежувати виконання та нагадує про баланс між активністю й відпочинком.

## Можливості

- Перегляд плану дня та загального прогресу у відсотках.
- Відмітка звичок як виконаних і можливість скасувати відмітку.
- Фільтрація списку за станом: усі, у плані, виконані.
- Додавання власної звички з вибором категорії.
- Автоматичне збереження плану й прогресу в `localStorage`.
- Скидання щоденного прогресу при першому відкритті застосунку в новий день.
- Інтерактивна картка підтримки: кнопка оновлення змінює намір і надихаюче повідомлення.
- Дружнє сповіщення після п'яти хвилин бездіяльності.
- Адаптивна верстка, керування формою клавішею Escape та видимі стани фокусу.

## Технології та бібліотеки

- **React** — компоненти, стан і реактивне оновлення інтерфейсу.
- **Vite** — локальний сервер розробки та production-збірка.
- **React Icons (`react-icons`)** — іконки навігації, звичок, категорій і кнопок.
- **React Toastify (`react-toastify`)** — сповіщення про виконання/додавання звичок і нагадування про перерву.
- **React Idle Timer (`react-idle-timer`)** — визначення п'яти хвилин бездіяльності, після яких показується нагадування.

Додаткові бібліотеки з переліку в завданні не використовуються: графік прогресу реалізовано засобами CSS, а картки кредитних карток і вибір кольору не відповідають темі планувальника звичок.

## Встановлення та запуск

Потрібні Node.js (20.19+ або 22.12+) і npm.

```bash
npm install
npm run dev
```

Vite покаже локальну адресу застосунку в терміналі.

## Деплой на Netlify

У репозиторії є `netlify.toml` із налаштуваннями для Vite: Netlify встановлює залежності, запускає `npm run build` і публікує `dist/`. Під час підключення GitHub-репозиторію `freshfenix/react-11` обери гілку `main`; базову директорію залиш порожньою, бо застосунок розташований у корені репозиторію. Після першого деплою наступні оновлення гілки `main` публікуватимуться автоматично.

## Як користуватися

1. Познач звичку кнопкою-прапорцем; прогрес, підсумок дня та статистика оновляться одразу.
2. Перемикай фільтри «Усі», «У плані» та «Виконані».
3. Натисни «Нова звичка», введи назву, вибери категорію та додай її до плану. Форму можна закрити кнопкою Escape або натисканням поза нею.
4. Натисни кнопку зі стрілками в картці щоденної підтримки, щоб переглянути інше нагадування.

## Як працюють бібліотеки

- `react-icons`: компоненти `Fi...` використовуються безпосередньо в JSX для зрозумілих іконок замість текстових символів.
- `react-toastify`: `toast.success`, `toast.info` і `toast.error` дають зворотний зв'язок після дій або помилки сховища; `ToastContainer` розміщений у кореневому компоненті.
- `react-idle-timer`: хук `useIdleTimer` слухає активність сторінки, позначає стан паузи та показує Toastify-нагадування після налаштованого тайм-ауту.

## Зберігання даних

Список звичок зберігається локально у браузері під ключем `dayflow-habits`. Це демопроєкт без сервера: дані доступні лише в поточному браузері й профілі. Коли дата збереженого плану не збігається з поточною локальною датою, застосунок починає день із початкового набору звичок. Очищення даних сайту в браузері також видаляє збережений план.
